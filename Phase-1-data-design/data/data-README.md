# Synthetic Data Disclaimer

All data in this folder is **entirely synthetic**, generated using the Python
Faker library (`en_GB` locale) via `data-generator.py` in this repository. No
real customer, policy, or claims information is included anywhere in this
project.

Names, addresses, dates of birth, email addresses, and phone numbers are all
randomly generated and do not correspond to any real individual, living or
deceased.

These files also contain deliberately-planted data quality issues (duplicate
customers, malformed postcodes, orphaned claims, inconsistent formatting) —
see `data-quality-rules.md` for the full list. These are intentional design
choices for demonstrating data quality detection, not accidental defects.
